One funny line for the [make.fun bounty "The One-Line Laugh"](https://make.fun/bounty/u-ronigrv-the-one-line-laugh-7ccca46f): a single sentence of at most 200 characters, judged pairwise by the house judge on surprise, everyday truth, economy of words and freshness.

## The line

> I bought a standing desk to fix my posture, and now I slouch at a healthier height.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt`. Deterministic: the same bytes on every run. No network access at run time.
